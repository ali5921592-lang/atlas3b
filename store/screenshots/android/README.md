# Android listing screenshots

- `01-male-atlas.png` — male reference, layered 3D atlas
- `02-female-atlas.png` — female reference and its current model coverage
- `03-section-controls.png` — section-plane controls

They are useful for a draft Google Play listing. They are not physical-device evidence, iOS screenshots, or proof of complete anatomy coverage. Re-capture from the release build on supported physical devices before submission.
